# Об образовании избирательных участков

В соответствии с пунктом 1 статьи 23 Конституционного Закона Республики Казахстан «О выборах в Республике Казахстан», РЕШИЛ:

1. По согласованию с Таразской городской территориальной избирательной комиссией образовать избирательные участки по городу Тараз согласно приложению 1 к настоящему решению.

2. Признать утратившими силу некоторые решения акима города Тараз согласно приложению 2 к настоящему решению.

3. Контроль за исполнением настоящего решения возложить на руководителя аппарата акима города Тараз.

4. Настоящее решение вводится в действие со дня его первого официального опубликования.

**Аким города Тараз**

**Б. Орынбеков**

> *«СОГЛАСОВАНО»*  
> *Таразская городская территориальная*  
> *избирательная комиссия*


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`part001`](rus/part001.md) | `!` Избирательные участки по городу Тараз |
| [`part002`](rus/part002.md) | Перечень утративших силу некоторых решений акима города Тараз |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
