# Сайлау учаскелерін құру туралы

«Қазақстан Республикасындағы сайлау туралы» Қазақстан Республикасының Конституциялық Заңының 23-бабы 1-тармағына сәйкес, ШЕШТІМ:

1. Тараз қалалық аумақтық сайлау комиссиясының келісімімен Тараз қаласы бойынша сайлау учаскелері осы шешімнің 1-қосымшасына сәйкес құрылсын.

2. Осы шешімнің 2-қосымшасына сәйкес Тараз қаласы әкімінің кейбір шешімдерінің күші жойылды деп танылсын.

3. Осы шешімнің орындалуын бақылау Тараз қаласы әкімі аппаратының басшысына жүктелсін.

4. Осы шешім оның алғашқы ресми жарияланған күнінен бастап қолданысқа енгізіледі.

**Тараз қаласының әкімі**

**Б. Орынбеков**

> *«КЕЛІСІЛДІ»*  
> *Тараз қалалық аумақтық*  
> *сайлау комиссиясы*


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`part001`](kaz/part001.md) | `!` Тараз қаласы бойынша сайлау учаскелері |
| [`part002`](kaz/part002.md) | Тараз қаласы әкімінің күші жойылған кейбір шешімдерінің тізбесі |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
