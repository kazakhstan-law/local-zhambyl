# Об утверждении Программы по управлению коммунальными отходами города Тараз на 2024-2029 годы

В соответствии с подпунктом 1) пункта 3 статьи 365 Экологического кодекса Республики Казахстан Таразский городской маслихат РЕШИЛ:

1. Утвердить Программу по управлению коммунальными отходами города Тараз на 2024-2029 годы согласно приложению к настоящему решению.

2. Настоящее решение вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

**Председатель Таразского городского маслихата**

**К. Олжабай**

> *Приложение к решению*  
> *Таразского городкого маслихата*  
> *от 26 декабря 2024 года № 25-12*


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`part001`](rus/part001.md) | ПРОГРАММА по управлению коммунальными отходами в городе Тараз на 2024-2029 годы |
| [`sec001`](rus/sec001.md) | `!` 1. ВВЕДЕНИЕ |
| [`sec001-t001`](rus/sec001-t001.md) | таблица 1 |
| [`sec001-part002`](rus/sec001-part002.md) | `!` sec001-part002 |
| [`sec001-t002`](rus/sec001-t002.md) | таблица 2 |
| [`sec001-part004`](rus/sec001-part004.md) | sec001-part004 |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
