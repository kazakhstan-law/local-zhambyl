# Об утверждении плана по управлению пастбищами и их использованию по городу Каратау и сельских округов Таласского района на 2022-2023 годы

В соответствии со статьей 17 Земельного Кодекса Республики Казахстан, подпунктом 1) пункта 1 статьи 9 Закона Республики Казахстан от 20 февраля 2017 года «О пастбищах», статьями 31, 37 Закона Республики Казахстан от 23 января 2001 года «О местном государственном управлении и самоуправлении в Республике Казахстан»,Таласский районный маслихат РЕШИЛ:

1. Утвердить план по управлению пастбищами и их использованию по городу Каратау и сельских округов Таласского района на 2022-2023 годы:

   1) по Аккольскому сельскому округу согласно приложению 1;

   2) по Аккумскому сельскому округу согласно приложению 2;

   3) по Бериккаринскому сельскому округу согласно приложению 3;

   4) по Бостандыксому сельскому округу согласно приложению 4;

   5) по Каратаускому сельскому округу согласно приложению 5;

   6) по Каскабулакскому сельскому округу согласно приложению 6;

   7) по Кенесскому сельскому округу согласно приложению 7;

   8) по Кокталскому сельскому округу согласно приложению 8;

   9) по Кызылаутскому сельскому округу согласно приложению 9;

   10) по Ойыкскому сельскому округу согласно приложению 10;

   11) по С.Шакировскому сельскому округу согласно приложению 11;

   12) по Ушаралскому сельскому округу согласно приложению 12;

   13) по Тамдинскому сельскому округу согласно приложению 13;

2. Конроль за исполнением данного решения возложить на председателя постоянной комиссии районного маслихата по защите проектов договоров по закупу земельных участков и прочего недвижимого имущества А.Ахметова.

3. Настоящее решение вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

**И.о секретаря маслихата**

**Т. Капсаланов**
