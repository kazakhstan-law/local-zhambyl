# Сайлау учаскелерін құру туралы

«Қазақстан Республикасындағы сайлау туралы» Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі Конституциялық Заңының 23 бабына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңының 33 бабына сәйкес Жамбыл ауданының әкімі ШЕШІМ ҚАБЫЛДАДЫ:

1. Қосымшаға сәйкес Жамбыл облыстық аумақтық сайлау комиссиясының келісімімен Жамбыл ауданының аумағында сайлау учаскелері құрылсын.

2. «Сайлау учаскелерін құру туралы» Жамбыл ауданы әкімінің 2014 жылғы 28 ақпандағы №1 шешімінің (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде №2125 болып тіркелген, 2014 жылдың 19 наурызында аудандық «Шұғыла-Радуга» газетінде жарияланған) күші жойылды деп танылсын.

3. Осы шешімнің орындалуын бақылау аудан әкімінің аппарат басшысы Жомарт Тешебайұлы Телеуовке жүктелсін.

4. Осы шешім әділет органдарында мемлекеттік тіркелген күннен бастап күшіне енеді және оның алғашқы ресми жарияланған күннен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.
